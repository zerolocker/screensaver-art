# Brand and logo

The logo's shape is generated by [`generate-logo.mjs`](generate-logo.mjs). Edit the script, not the SVGs.

## Brand

- **Positioning:** a curated daily art channel, not another wallpaper engine. "Turn your screensaver into a living gallery."
- **Audience:** Mac users who care how their screen looks: designers, writers, developers, the desk-setup crowd, people who enjoy AI art but don't want to make it.
- **Voice:** quiet, tasteful, like a gallery. Honest, never hypey. The art does the talking.
- **Visual language:** near-black `#0b0b0c`, mint `#9ee8a2` (`--primary`), dark green `#0d2114` (`--primary-foreground`); Playfair Display headlines with an italic green accent, Inter body text; frosted pills; rounded tiles with a soft mint glow.

## The mark

A single tapered brushstroke winding into a spiral: classic art in motion. The swirl recalls painterly motion (Van Gogh's sky, Hokusai's wave), the tapering stroke reads as movement, and the spiral returning on itself suggests the nightly cycle. It has no letters, sparkles or "AI" clichés.

It's pure geometry (a log-spiral centreline with a tapered width, drawn as one filled path), so it stays crisp from a 1024 px app icon down to a 16 px favicon.

## Files

| File | Use |
|---|---|
| `logo-tile.svg` | App icon: ink swirl on a mint rounded tile. Source for the favicon and raster icons. |
| `logo-mark-ink.svg` | Bare swirl in ink, for mint or light backgrounds |
| `logo-mark-mint.svg` | Bare swirl in mint, for the near-black site |
| `living-art-screensaver-web/public/icon.svg` | Favicon (copy of the tile, written by the generator) |
| `living-art-screensaver-web/lib/logo-path.ts` | The path, used by `components/logo-mark.tsx` and the OG image |
| `living-art-screensaver-web/public/apple-icon.png` | 180×180 tile |
| `electron-app/build/icon.png` | 1024×1024 tile; electron-builder makes the platform icons from it |

**Lockups.** In the product: the mint tile plus "Living Art Screensaver" in Inter semibold. In marketing: the bare mint swirl plus *Living Art* in Playfair Display italic.

**Rules.** Use exactly one brand colour, never a gradient or outline. Leave clear space of at least half the mark's width. Over artwork, use a frosted pill rather than stamping the swirl on the art.

## Regenerating

```bash
node branding/generate-logo.mjs   # rewrites the SVGs and lib/logo-path.ts
```

To redraw the PNGs, render `logo-tile.svg` at the target size with any SVG rasterizer, for example headless Chromium with a transparent background:

```bash
chromium --headless --no-sandbox --hide-scrollbars \
  --default-background-color=00000000 --window-size=1024,1024 \
  --screenshot=electron-app/build/icon.png page-embedding-the-svg.html
```
